# Verified LIBERO evidence

Generated by `python scripts/experiments/export_research_evidence.py`.

- `runs.csv` / `runs.json`: complete and diagnostic evaluations, explicitly distinguished.
- Per run: relative-path manifest/summary, episode outcomes, count audit and source hashes.
- Where available: checkpoint training configuration, scalar training logs (gzip), training audit.
- Wilson intervals are descriptive episode-level intervals, not training-seed uncertainty.
- `step_tflops=0` in historical logs means unmeasured.
- Checkpoint weights, datasets, videos, environment credentials are excluded.

See [research assessment](../../docs/arxiv_readiness_20261018.md) for confounds and claim boundaries.
