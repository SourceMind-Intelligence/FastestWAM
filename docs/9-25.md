# 目标

基于 `OpenWAM-Alpha-Pretrain-Foundation-Model` 在 LIBERO 上做最小改动实验。

当前核心 hypothesis：

> 原始 MIP-2 在 LIBERO precision task（尤其 task06）表现不足，主要原因可能不是 2-step iterative computation 本身，而是 refinement training distribution 与 inference-time prediction error distribution 不匹配。

因此本轮最重要实验：

```text
MIP-2 + self-forcing-like refinement + stop-gradient
```

要求：

- 尽可能继承 OpenWAM Alpha pretrained prior
- Video DiT / Video FM 完全保持原生
- LIBERO 数据、optimizer、LR、batch、training budget 保持官方配置
- 同时比较 training steps 和 cumulative TFLOPs
- 3TB 磁盘下严格限制 checkpoint 数量

---

# 1. GPU 分配

8×H100 分成 4 个独立实验，每个实验 2 GPU：

```text
GPU 0-1: Run A - OpenWAM FM baseline
GPU 2-3: Run B - Original MIP-2
GPU 4-5: Run C - Mixed Self-Forcing MIP-2   [核心实验]
GPU 6-7: Run D - Pred Self-Forcing MIP-2
```

四组：

| Run | Action objective | Refinement input |
|---|---|---|
| A | OpenWAM FM | 原生 |
| B | Original MIP | `0.9 * GT + 0.1 * noise` |
| C | Mixed Self-Forcing | `0.9 * (0.5 GT + 0.5 pred0.detach()) + 0.1 noise` |
| D | Pred Self-Forcing | `0.9 * pred0.detach() + 0.1 noise` |

Run C 是本轮最核心实验。

如果计算资源或时间紧张，优先级：

```text
C > A > B > D
```

# 4. Run B：Original MIP-2

保留 Video FM。

Action 使用原始 MIP 思路。

## Step 1

```python
pred0 = action_dit(
    obs_features,
    action_input=torch.zeros_like(gt_action),
    action_timestep=0.0,
)

loss0 = masked_mse(pred0, gt_action)
```

## Step 2 training

```python
z = torch.randn_like(gt_action)

action_input_1 = (
    0.9 * gt_action
    + 0.1 * z
)

pred1 = action_dit(
    obs_features,
    action_input=action_input_1,
    action_timestep=0.9,
)

loss1 = masked_mse(pred1, gt_action)
```

如果严格复现原始 MIP：

```python
action_loss = loss0 + loss1
```

Inference：

```python
pred0 = action_dit(obs, zeros, t=0.0)

pred1 = action_dit(
    obs,
    0.9 * pred0,
    t=0.9,
)

final_action = pred1
```

# 5. Run C：Mixed Self-Forcing MIP-2

这是本轮最重要实验。

第一步：

```python
pred0 = action_dit(
    obs_features,
    action_input=torch.zeros_like(gt_action),
    action_timestep=0.0,
)

loss0 = masked_mse(pred0, gt_action)
```

第二步不再只使用 GT 附近 Gaussian corruption。

构造：

```python
anchor = (
    0.5 * gt_action
    + 0.5 * pred0.detach()
)
```

然后：

```python
z = torch.randn_like(gt_action)

action_input_1 = (
    0.9 * anchor
    + 0.1 * z
)
```

第二次预测：

```python
pred1 = action_dit(
    obs_features,
    action_input=action_input_1,
    action_timestep=0.9,
)

loss1 = masked_mse(pred1, gt_action)
```

总 Action loss：

```python
action_loss = loss0 + loss1
```

必须：

```python
pred0.detach()
```

即 refinement loss 不通过第二步输入反传进第一步 prediction。

目的：

```text
让 refinement network 在训练时看到更接近 inference 时真实出现的 prediction errors。
```

Inference 与 Original MIP-2 完全相同：

```text
0
 -> pred0
 -> 0.9 * pred0
 -> pred1
 -> execute
```

# 6. Run D：100% Prediction Self-Forcing

用于判断 prediction-conditioned refinement 的上限。

```python
pred0 = action_dit(obs, zeros, t=0)

anchor = pred0.detach()

action_input_1 = (
    0.9 * anchor
    + 0.1 * torch.randn_like(anchor)
)

pred1 = action_dit(
    obs,
    action_input_1,
    t=0.9,
)

loss = mse(pred0, gt) + mse(pred1, gt)
```

风险：

```text
训练早期 pred0 质量差，第二阶段可能看到过多 off-manifold states。
```

因此 Run D 是 ablation，不是主方案。

# 8. TFLOPs 对齐

这是本轮必须完成的部分。

不能只比较：

```text
10k steps vs 10k steps
```

因为 MIP-2 训练包含两次 Action forward，而 FM 通常一次 Action forward。

真实成本：

```text
FM:
    Video forward/backward
    + 1 × Action forward/backward

MIP:
    Video forward/backward
    + 2 × Action forward
    + corresponding backward
```

但 Video DiT 通常占大量计算，因此 MIP 总 FLOPs 不一定是 FM 的 2 倍。

必须实测。

WandB 记录：

```text
compute/step_flops
compute/step_tflops
compute/cumulative_tflops

compute/video_forward_flops
compute/action_forward_flops
compute/total_forward_flops

compute/train_step_time
```

如果无法精确测 kernel FLOPs，至少使用同一 FLOP estimator 对所有 runs 一致计算。

最终必须画：

```text
Success Rate vs Training Steps
Success Rate vs Cumulative TFLOPs
```

第二张是主要公平比较。

# 9. TFLOPs checkpoint 对齐

先跑 FM baseline 一小段，得到：

```text
TFLOPs / training step
```

再得到：

```text
MIP TFLOPs / training step
```

假设：

```text
FM step cost = C_FM
MIP step cost = C_MIP
```

FM 10k steps 总 budget：

```text
Budget = 10000 * C_FM
```

MIP compute-matched 最大 step：

```text
MIP_matched_steps
=
10000 * C_FM / C_MIP
```

例如如果实际：

```text
C_MIP / C_FM = 1.25
```

则 compute-matched MIP：

```text
8000 steps
```

因此同时报告：

```text
same-step:
FM 10k vs MIP 10k

same-FLOPs:
FM 10k vs MIP ~8k
```

不要只报告其中之一。

# 11. 3TB 磁盘下的 checkpoint 策略

绝对不要每几百 step 保存完整 optimizer checkpoint。

首先训练前做一次测试：

```text
保存一个完整 checkpoint
du -sh <checkpoint>
```

分别记录：

```text
model-only checkpoint size
full resumable checkpoint size
```

然后根据真实大小决定最终保留数量。

## 每个 run 只保留

### A. 1 个 latest resumable checkpoint

包含：

```text
model
optimizer
scheduler
global step
RNG state
scaler
```

用于断点续训。

采用 rotate：

```text
latest-full/
```

每次新的 full checkpoint 成功写完后，再删除旧的。

任何时刻每个 run：

```text
最多 1 个 full resumable checkpoint
```

---

### B. milestone checkpoint 只保存 model weights

建议：

```text
step_2000_model_only
step_4000_model_only
step_6000_model_only
step_8000_model_only
step_10000_model_only
```

不要包含：

```text
optimizer state
scheduler state
gradient state
```

这些 checkpoint 只用于 evaluation。

---

### C. Best checkpoint

额外维护：

```text
best_overall_model_only
best_task06_model_only
```

如果新的 checkpoint 更好：

```text
覆盖旧 best
```

不要无限累积。


# 17. 磁盘安全阈值

训练脚本增加 disk guard。

例如：

```python
if free_disk < 300GB:
    disable_nonessential_checkpoint_save()
    warn()
```

如果：

```text
free_disk < 150GB
```

则：

```text
停止保存 evaluation artifacts / videos
只保留 latest resumable checkpoint
```

不要等磁盘 100% 满。

训练任务因为 checkpoint 写盘失败可能直接损坏 checkpoint。

# 19. 最关键的判断标准

第一优先：

```text
Mixed Self-Forcing MIP-2
是否明显改善 task06？
```

即：

```text
task06:
Mixed MIP-2 >> Original MIP-2
```

第二优先：

```text
overall success rate 是否不下降甚至提升？
```

第三优先：

```text
在相同 cumulative TFLOPs 下是否优于 Original MIP / FM？
```

最理想结果：

```text
Mixed MIP-2
    task06 ↑
    Long ↑
    overall ↑
    inference NFE = 2
```

同时：

```text
same-TFLOPs performance
>= OpenWAM FM baseline
```

# 最终执行顺序

1. 确认官方 OpenWAM LIBERO config。
2. 确认 2-GPU effective batch 与 baseline 一致。
3. 跑 100~200 steps smoke test。
4. 测真实 checkpoint size。
5. 测 FM / MIP 每 step FLOPs。
6. 根据真实 FLOPs 计算 compute-matched training steps。
7. 同时启动 4 个 2×H100 runs。
8. milestone 仅保存 model-only。
9. 每个 run 最多保留 1 个完整 resumable checkpoint。
10. 重点追踪 task06、Long、overall、cumulative TFLOPs。
11. 最终同时报告 same-step 和 same-TFLOPs comparison。

核心实验：

```text
OpenWAM Alpha Pretrain
        +
unchanged Video FM
        +
MIP-2
        +
prediction-conditioned refinement
        +
stop-gradient
```

核心问题：

> 在不改变 OpenWAM world representation 和 Video generation prior 的情况下，让 Action refinement 在训练时看到自身 prediction error，能否修复 MIP-2 在 LIBERO precision task 上的失败，同时维持 2-step inference 的效率优势？
