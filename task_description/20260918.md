3. Video loss 保持原始 Flow Matching：
   L = lambda_video * L_video_FM + lambda_action * L_action_MIP

4. 将 Action Flow Matching loss 替换成 MIP。所有计算都在 normalized action space。

   设 GT action 为 A，t_star=0.9。

   Branch 1:
       I0 = zeros_like(A)
       pred0 = model(..., action_input=I0, action_timestep=0.0)
       L0 = masked_MSE(pred0, A)

   Branch 2:
       z = randn_like(A)
       I09 = 0.9 * A + 0.1 * z
       pred09 = model(..., action_input=I09, action_timestep=0.9)
       L09 = masked_MSE(pred09, A)

   Action loss:
       L_action_MIP = 0.5 * (L0 + L09)

   沿用原有 action validity mask。

5. MIP inference 改成 deterministic 2-step，不再使用 Flow scheduler / Euler integration：

       a0 = model(..., action_input=zeros, action_timestep=0.0)
       a1 = model(..., action_input=0.9 * a0, action_timestep=0.9)
       action = unnormalize(a1)

   inference 不采样 Gaussian noise，严格只有 2 次 MIP iteration。

6. 不要删除原 Flow 实现，新增配置：
       action_objective: flow | mip
   确保 `flow` 模式行为与原 OpenWAM 完全一致。
